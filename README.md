## 这是什么

一份**持续更新的作品集**。定位是「工作版」：内容仍在校对补充，定稿后会发到公开平台。

放在 GitHub Pages 而不是公开内容平台，理由是**这里的版本可以随时改**，而公开平台的文章一发出去就冻结了。

## 更新规矩（自己守）

1. **只放已交付的东西**。没写完的条目不上页面——「待完成」占位是负资产。
2. 每次改动在首页 `更新日志` 加一行，并改 `2026-XX-XX` 日期。
3. 首页 HTML 里的 `<meta name="robots" content="noindex, nofollow">` 与根目录 `robots.txt` 是低曝光的实现手段——**改名不能替代它**。
4. 团队项目材料对外前先发群里知会一声。
