多 agent 援引辩论

开源

CrewAI　·　3 agent / 7 task　·　Python　·　2026.09

把「辩义 / 案查 / 裁断」三方援引辩论协议移植成 crew：agent 物理隔离、检索工具只给辩义者、条件任务跳过、报告由代码拼装而非模型自述。 核心包 1,769 行，pytest 62 项通过，另含三题验收与变体扫描；带一条命令即可复现的 dry-run 路径（零 LLM 成本）。
